# Entry point for Claude Code and other AI assistants

The engineering rules of this repository live in `AGENTS.md`, at the root. Read `AGENTS.md` and `README.md`
before touching code, every session; do not rely on memory from a previous conversation. Some tools load
`CLAUDE.md` automatically but not `AGENTS.md`, so this file exists only to force that read.

Follow the "Required reading" list in `AGENTS.md` and read only the docs relevant to the change.
